# Security policy

OpenFriend is pre-release. Please report suspected vulnerabilities privately
rather than opening a public issue.

Email `theandrewsiah+openfriend@gmail.com` with:

- a description of the issue and potential impact;
- affected commit, route, or component;
- reproduction steps or a proof of concept;
- any suggested mitigation.

Do not include real personal conversations, tokens, or unrelated account data.
The maintainer will acknowledge a report as soon as practical and coordinate
disclosure after a fix is available.

Only the latest `main` branch is supported during early development.

For the product security and privacy model, see
[docs/SECURITY.md](docs/SECURITY.md).
